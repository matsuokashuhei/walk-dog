Owner 表示名登録 API

認証済み Owner の現在値を取得し、表示名を登録する。 Base URL は /v1。日時は ISO 8601 UTC、JSON は camelCase。

認証は Authorization: Bearer <access_token>。 displayName は前後空白除去後 1〜100 文字。認証直後は null。
エンドポイント
  • GET /v1/owner
  • PATCH /v1/owner

GET/v1/owner

Access Token に対応する Owner を返す。セッション復元時の displayName 照合に使う。

Request parameters

Parameters

NameInRequiredDescription
accept header required application/json を要求する。
authorization header required Cognito Access Token。Bearer <access_token>。
x-request-id header optional 相関 ID。未指定時は API が生成する。

Header

  • accept — application/json を要求する。
  • authorization — Cognito Access Token。Bearer <access_token>。
  • x-request-id — 相関 ID。未指定時は API が生成する。

なし

なし

なし

Response

Status

500サーバーエラーfalse

Body

avatarUrlstring | nullAvatar の参照
createdAtstring (date-time)作成日時（ISO 8601 UTC）
updatedAtstring (date-time)更新日時（ISO 8601 UTC）

PATCH/v1/owner

表示名を登録し、更新後の Owner を返す。登録画面の送信がこのエンドポイントを使う。

Request parameters

Parameters

NameInRequiredDescription
accept header required application/json を要求する。
authorization header required Cognito Access Token。Bearer <access_token>。
content-type header required application/json。
x-request-id header optional 相関 ID。未指定時は API が生成する。
displayName body required 前後空白除去後、1〜100 文字の表示名。

Header

  • accept — application/json を要求する。
  • authorization — Cognito Access Token。Bearer <access_token>。
  • content-type — application/json。
  • x-request-id — 相関 ID。未指定時は API が生成する。

Path

なし

Query

なし

Body

FieldTypeRequiredDescription
displayName string required 前後空白を除去したあと、空文字ではなく 1〜100 文字。 
{
  "displayName": "Akira"
}

Response

Status

StatusMeaningretryable
200更新後の Owner—
400入力不正（欠如、空、空白のみ、101 文字以上）false
401Access Token 欠如または不正false
500サーバーエラーfalse

Body

200 は GET と同じ Owner リソース。設定後の displayName は保存した値。

400 / 401 / 500 はエラー契約。

FieldTypeDescription
code string INVALID_INPUT、UNAUTHENTICATED、または INTERNAL_ERROR
messagestring画面に表示する理由
requestIdstring相関 ID
retryableboolean同じ要求で再試行できるか

Example

Request

curl -X PATCH "$API_BASE_URL/v1/owner" \
  -H "Accept: application/json" \
  -H "Authorization: Bearer $ACCESS_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"displayName":"Akira"}'
