Owner 表示名登録 画面モック

OTP 成功後およびセッション復元時に displayName が未設定なら、この画面で表示名を登録する。 登録成功後は認証済みホームへ進む。Settings の Sign Out はこの画面から到達できる。

Route: /owner/display-name → 成功時 認証済みホーム。 API: GET /v1/owner（復元時照合）、PATCH /v1/owner（{ displayName }）。

コンポーネント一覧

  • DisplayNameScreen — 登録画面の枠
  • Title — 「表示名を登録」
  • HelpText — 1〜100文字の案内
  • DisplayNameField — 表示名入力
  • SubmitButton — 登録する
  • ValidationMessage — 入力エラー
  • RetryableError — API 再試行可能な失敗
  • SubmittingStatus — 送信中
  • SettingsLink — Settings（Sign Out）へ

イベント一覧

  • onChangeDisplayName — 入力値を更新する
  • onSubmit — 前後空白を除去して PATCH /v1/owner を送る
  • onRetry — 同じ表示名で再送信する
  • onOpenSettings — /settings へ進む
