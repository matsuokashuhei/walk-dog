Dog 一覧・登録 API

認証済み Owner の Dog を一覧し、Name と Gender で登録する。登録と同時に Daily 30分の Goal Revision を作成する。 Base URL は /v1。日時は ISO 8601 UTC、JSON は camelCase。

認証は Authorization: Bearer <access_token>。 name は同一 Owner 内で一意、前後空白除去後 1〜100 文字。 gender は male / female / unknown。 birthday 省略時の精度は unknown。 avatarUrl は応答に含め、登録時のアップロードはこの API に含めない。
エンドポイント
  • GET /v1/dogs
  • POST /v1/dogs
  • GET /v1/dogs/:dogId

POST/v1/dogs

Dog を登録し、Daily 30分の Goal Revision を作成して返す。登録画面の送信がこのエンドポイントを使う。

Request parameters

Parameters

NameInRequiredDescription
accept header required application/json を要求する。
authorization header required Cognito Access Token。Bearer <access_token>。
content-type header required application/json。
x-request-id header optional 相関 ID。未指定時は API が生成する。
name body required 前後空白除去後、1〜100 文字。同一 Owner 内で一意。
gender body required male / female / unknown。
birthday body optional Partial Birthday。省略時の精度は unknown。

Header

  • accept — application/json を要求する。
  • authorization — Cognito Access Token。Bearer <access_token>。
  • content-type — application/json。
  • x-request-id — 相関 ID。未指定時は API が生成する。

Path

なし

Query

なし

Body

FieldTypeRequiredDescription
name string required 前後空白を除去したあと、空文字ではなく 1〜100 文字。同一 Owner 内で一意。
gender string required male / female / unknown。
birthday object optional precision は unknown / year / month / day。 year は year 以上、month は month 以上、day は day で必須。 
{
  "name": "Mugi",
  "gender": "female",
  "birthday": { "precision": "day", "year": 2020, "month": 4, "day": 12 }
}

Response

Status

StatusMeaningretryable
201作成した Dog と Daily 30分 Goal Revision—
400入力不正（欠如、空、空白のみ、101 文字、gender / birthday 不正）false
401Access Token 欠如または不正false
409同一 Owner 内の Name 重複false
500サーバーエラーfalse

Body

201 は Dog と、登録時に作成した Daily 30分の currentGoal。GET の配列要素と同じ形。

FieldTypeDescription
requestIdstring相関 ID
dogIdstring (UUID)Dog を一意に識別する
ownerIdstring (UUID)管理 Owner
namestring前後空白除去済みの 1〜100 文字
genderstringmale / female / unknown
birthdayobjectPartial Birthday。精度と入力した年月日。省略時は { "precision": "unknown" }
avatarUrlstring | nullAvatar の参照。このセッションの登録では null
createdAtstring (date-time)作成日時（ISO 8601 UTC）
updatedAtstring (date-time)更新日時（ISO 8601 UTC）
currentGoal.goalRevisionIdstring (UUID)登録時に発行する Goal Revision
currentGoal.periodstringdaily
currentGoal.minutesinteger30
currentGoal.effectiveFromstring (date-time)適用開始日時。登録日時
currentGoal.effectiveTostring (date-time) | null次 Revision 直前まで。登録直後は null

400 / 401 / 409 / 500 はエラー契約。

FieldTypeDescription

messagestring画面に表示する理由。重複時は「同じ名前のDogが既に存在します。」

retryableboolean同じ要求で再試行できるか
