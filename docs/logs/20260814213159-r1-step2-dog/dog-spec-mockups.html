Dog 一覧・登録 画面モック

認証済みホームは Dogs List を表示する。Empty から、または追加操作で Register Dog へ進み、 Name と Gender を登録する。成功時に Daily 30分の Goal Revision が作られ、一覧へ戻る。 一覧の行からプロフィール Detail を開く。

Routes: Dogs List（認証済みホーム） → /dogs/new または /dogs/:dogId。 API: GET /v1/dogs、POST /v1/dogs（{ name, gender, birthday? }）、GET /v1/dogs/:dogId。 Walk 開始時の選択、Edit、Avatar、タブ（Walk / Me）、履歴はこのセッションの画面に含めない。

コンポーネント一覧

  • DogsListScreen — 一覧の枠
  • Title — 「Dogs」
  • AddDogButton — 登録へ進む
  • EmptyState — 0件と登録操作
  • LoadingState — 取得中
  • DogRow — 名前と Daily 30分 Goal。タップで Detail へ
  • RetryableError — 一覧または Detail の再試行
  • SettingsLink — Settings（Sign Out）へ
  • DogDetailScreen — プロフィール Detail の枠
  • ProfileFields — 名前、Gender、Birthday、Daily 30分 Goal
  • RegisterDogScreen — 登録画面の枠
  • NameField — 名前入力
  • GenderChoice — Male / Female / Unknown
  • BirthdayField — 任意。精度 Unknown / 年 / 年月 / 年月日
  • GoalHint — 登録時に Daily 30分を作成する案内
  • SubmitButton — 登録する
  • DiscardDialog — 未保存入力の破棄確認

イベント一覧

  • onOpenRegister — /dogs/new へ進む
  • onOpenDetail — /dogs/:dogId へ進む
  • onRetryList — GET /v1/dogs を再実行する
  • onRetryDetail — GET /v1/dogs/:dogId を再実行する
  • onBackToList — List へ戻る
  • onOpenSettings — /settings へ進む
  • onChangeName — 名前を更新する
  • onChangeGender — Gender を更新する
  • onChangeBirthday — Birthday の精度と値を更新する
  • onSubmit — 前後空白を除去して POST /v1/dogs を送る
  • onRetrySubmit — 同じ入力で再送信する
  • onBack — 未保存があれば確認し、なければ List へ戻る
  • onConfirmDiscard — 入力を捨てて List へ戻る
  • onCancelDiscard — 入力を保持して登録画面に残る
