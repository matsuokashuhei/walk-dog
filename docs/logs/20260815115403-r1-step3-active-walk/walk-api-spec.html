Active Walk API

認証済み Owner の Active Walk を照会し、開始し、Completed にする。位置情報許可の取り消しでは指定 Walk を Failed にする。 Base URL は /v1。日時は ISO 8601 UTC、JSON は camelCase。

認証は Authorization: Bearer <access_token>。 1 Owner につき Active Walk は最大 1件。 POST /v1/walks は開始に成功すると recording を返す。 Idempotency-Key は開始と Finish で必須。Endpoint ごとに別名前空間。有効期間は処理開始から 24時間。 TrackPoint と Event はこの API に含めない。
エンドポイント
  • GET /v1/walks/active
  • POST /v1/walks
  • POST /v1/walks/:walkId/finish
  • DELETE /v1/walks/:walkId

POST/v1/walks

x-request-id header optional 相関 ID。未指定時は API が生成する。
participantDogIds body required 同一 Owner が管理する Dog の UUID 配列。1件以上、重複なし。
