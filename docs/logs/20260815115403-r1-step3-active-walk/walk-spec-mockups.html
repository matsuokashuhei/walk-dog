Active Walk 画面モック

認証済みシェルの Walk タブは Ready / Starting / Recording / Completed / Failed を表示する。 同じ Owner の Dog を1頭以上選び、foreground と background の位置情報を許可すると Start できる。 位置情報を許可しているときは、画面背景を Apple MapKit の地図にし、現在地を表示する。 開始成功後は Recording、Finish 成功後は Completed、破棄時は Failed。

Route: /(tabs)/walk。タブは Dogs と Walk。 API: GET /v1/walks/active、POST /v1/walks、POST /v1/walks/:walkId/finish、DELETE /v1/walks/:walkId。 位置情報許可時の地図は Apple MapKit。現在地のみ表示し、TrackPoint の経路は描かない。 TrackPoint、Event、Walk Detail、Goal progress、Owner タブはこのセッションの画面に含めない。

コンポーネント一覧

  • WalkTabs — Dogs / Walk
  • WalkScreen — Walk タブの枠
  • ReadyState — Dog 選択と Start
  • DogPickRow — 選択できる Dog
  • StartCondition — 不足理由（未選択 / 位置情報）
  • AllowLocationButton — foreground / background 許可を求める
  • MapBackground — 許可済みのとき Apple MapKit を背景にする
  • CurrentLocation — 端末の現在地
  • StartButton — 開始条件が揃ったとき有効
  • StartingState — 開始要求中
  • RecordingState — Participant 名と経過時間、Finish
  • ElapsedTime — startedAt からの経過
  • FinishButton — Completed への遷移を要求
  • CompletedState — 所要時間、距離 0、Participant
  • FailedState — 破棄後の理由と Ready へ戻る操作
  • RetryableError — 同じ操作の再試行
  • EmptyDogs — Dog 0件と登録導線

イベント一覧

  • onOpenWalk — Walk タブを開き GET /v1/walks/active と Dog 一覧を照合する
  • onToggleDog — Participant 候補の選択を切り替える
  • onAllowLocation — foreground / background 位置情報の許可を求める
  • onStart — 選択した participantDogIds で POST /v1/walks を送る
  • onRetryStart — 同じ選択で開始を再送する
  • onFinish — POST /v1/walks/:walkId/finish を送る
  • onRetryFinish — 同じ Finish を再送する
  • onBackToReady — Completed / Failed から Ready へ戻る
  • onRetryLoad — Ready の取得を再実行する
  • onOpenRegister — Dog 0件から /dogs/new へ進む
