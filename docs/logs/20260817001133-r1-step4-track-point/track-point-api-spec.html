TrackPoint API

認証済み Owner が Recording 中の Walk へ、10秒ごとに取得した位置を送る。 API は SQS へ受理し、受理した TrackPoint を返す。worker が DynamoDB へ確定する。 Base URL は /v1。日時は ISO 8601 UTC、JSON は camelCase。

認証は Authorization: Bearer <access_token>。 TrackPoint は recording の Walk が受け付ける。 順序と冪等の正本は recordedAt。同一 walkId と recordedAt の再送は冪等。 Idempotency-Key はこの endpoint では使わない。
エンドポイント
  • POST /v1/walks/:walkId/track-points

POST/v1/walks/:walkId/track-points

Access Token に対応する Owner の recording Walk へ TrackPoint を送る。 成功時は SQS へ受理し、TrackPoint を返す。

Request parameters

Parameters

NameInRequiredDescription
walkId path required 対象 Walk。UUID。
accept header required application/json を要求する。
authorization header required Cognito Access Token。Bearer <access_token>。
content-type header required application/json。
x-request-id header optional 相関 ID。未指定時は API が生成する。

Header

  • accept — application/json を要求する。
  • authorization — Cognito Access Token。Bearer <access_token>。
  • content-type — application/json。
  • x-request-id — 相関 ID。未指定時は API が生成する。

Path

  • walkId — 対象 Walk。UUID。

Query

なし

Body

FieldTypeRequiredDescription
recordedAt string (date-time) required モバイルが位置を取得した時刻。ISO 8601 UTC。
latitude number required 緯度。-90 以上 90 以下。
longitude number required 経度。-180 以上 180 以下。

Body

201 は受理した TrackPoint。同一 walkId と recordedAt、同一 body の再送もこの形を返す。

400 / 401 / 404 / 409 / 429 / 5xx はエラー契約。

Example

Request

curl -X POST "$API_BASE_URL/v1/walks/0193f0c2-8d4a-7b21-9c55-1a2b3c4d5e80/track-points" \
  -H "Accept: application/json" \
  -H "Authorization: Bearer $ACCESS_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{
  "recordedAt": "2026-08-17T03:12:14.000Z",
  "latitude": 35.681236,
  "longitude": 139.767125
}'
