TrackPoint 画面

Recording 中の Walk 画面は Apple MapKit を背景にし、現在地にピンを置き、取得した TrackPoint を経路として描く。 10秒ごとに位置を送り、Background でも継続する。送信失敗は同じ点を自動再送する。

Walk 画面は Step 3 の Ready / Starting / Recording / Completed / Failed を継続する。 位置情報許可時の地図は Apple MapKit。現在地ピンと、端末が取得した点を recordedAt 順に結んだ経路を表示する。 距離・pace・Event・Walk Detail は後続。

コンポーネント一覧

  • MapBackground — 画面全体の背景を Apple MapKit の地図にする
  • CurrentLocationPin — 現在地にピンを置く
  • TrackPath — 取得した点を recordedAt 順に結んで経路を描く
  • RecordingOverlay — Participant 名と経過時間、Finish
  • TrackPointSampler — 10秒ごとに位置を取得する
  • OutboundQueue — recordedAt、latitude、longitude を保持する
  • TrackPointSender — POST /v1/walks/:walkId/track-points を送る
  • AutoRetry — retryable: true の失敗で同じ点を再送する

イベント一覧

  • onSampleLocation — 10秒ごとに位置を取得し、キューへ入れる。ピンは現在地へ移動し、経路に点を足す
  • onSendTrackPoint — キュー先頭を POST /v1/walks/:walkId/track-points で送る
  • onTrackPointAccepted — 201 を受けてその点をキューから外す
  • onAutoRetry — 再試行可能な失敗で同じ点を保持したまま再送する
  • onEnterBackground — Background でも取得と送信を継続する
