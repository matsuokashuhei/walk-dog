Finish API

認証済み Owner が Recording 中の Walk を Completed にする。 API は、その Walk の PostgreSQL 受理済み TrackPoint がすべて DynamoDB に揃うまで待ってから Completed を返す。

認証は Authorization: Bearer <access_token>。 モバイルは Finish 前に端末の outbound queue を空にする。 TrackPoint 0件は待ちなしで Completed。距離は 0。 Finish 用 Idempotency-Key は開始 Key と別名前空間。有効期間は処理開始から24時間。
エンドポイント
  • POST /v1/walks/:walkId/finish

POST/v1/walks/:walkId/finish

Access Token に対応する Owner の recording Walk を Completed にする。 PostgreSQL に受理済みの TrackPoint がすべて DynamoDB に存在するまで待ってから Completed Walk を返す。 TrackPoint 0件は待ちなし。確定待ちの再試行可能な失敗では Walk を recording のまま返し、同じ Finish を Retry できる。

Body

200 は Completed Walk。 durationSeconds は startedAt から completedAt までの秒。 distanceMeters はこの縦切りでは 0。 paceSecondsPerMeter は距離 0 のため null。 participants は開始時と同じ参加 Dog。

同一 Idempotency-Key と同一 body の再送は、完了済みなら Completed Walk を 200 で返す。処理中なら確定まで待ち、同じ結果を返す。

503 のとき Walk は recording のまま。クライアントは Recording を維持し、同じ Finish を Retry する。

400 / 401 / 404 / 409 / 500 / 503 はエラー契約。

messagestring画面に表示する理由。recording ではないときは「この散歩は終了できません。」。確定待ちの再試行可能な失敗は「終了処理を完了できませんでした。もう一度お試しください。」

  -H "Idempotency-Key: 0193f0c2-8d4a-7b21-9c55-1a2b3c4d5e91" \
