Finish 画面

Recording の Finish は、端末キューを吐き出したあと API が DynamoDB 確定を待って Completed にする。 失敗時は Recording を維持し、同じ Finish を Retry する。距離は 0。Walk Detail は後続。

Walk 画面の状態は Ready / Starting / Recording / Completed / Failed を継続する。 Finish 専用の新しい状態は増やさない。確定待ち中も Recording として扱い、操作は Finish の進行中表示と Retry に限る。 Event・距離算出・Walk Detail は後続。

コンポーネント一覧

  • RecordingOverlay — Participant 名と経過時間、Finish
  • OutboundQueueFlush — Finish 前に端末キューを空にする
  • FinishWalkRequest — POST /v1/walks/:walkId/finish と同一 Idempotency-Key
  • FinishRetry — 失敗時に Recording を維持し、同じ Finish を再試行する
  • CompletedSummary — 経過時間と距離 0 の完了表示

イベント一覧

  • onFinishPress — 位置取得を止め、outbound queue を吐き出す
  • onFlushComplete — キューが空になったら POST /finish を送る。残件があるあいだは Finish 失敗
  • onFinishSuccess — Completed を表示する。距離は 0
  • onFinishRetryableFailure — Recording を維持し、理由と手動 Retry を表示する
  • onFinishNonRetryableFailure — Recording を維持し、理由を表示する（状態が recording ではない場合など）
