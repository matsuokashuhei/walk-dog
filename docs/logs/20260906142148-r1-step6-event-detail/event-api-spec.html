Event + Detail API

認証済み Owner が Recording 中に Participant 別 Event を記録し、Completed Walk の Detail で経路・距離・時間・Event を取得する。 Finish は DynamoDB 確定 TrackPoint から距離と pace を返す。

Event の冪等キーはモバイル生成の eventId。Retry は同じ eventId・種別・Participant・発生時刻・位置を送る。 経路長は確定 TrackPoint を recordedAt 順に結んだメートル整数。距離 0 のとき pace は null。 履歴一覧（GET /v1/walks）はこの契約に含めない。
エンドポイント
  • POST /v1/walks/:walkId/events
  • GET /v1/walks/:walkId
  • POST /v1/walks/:walkId/finish（距離・pace）

POST/v1/walks/:walkId/events

Access Token に対応する Owner の recording Walk に Event を記録する。 同一 eventId で同一内容の再送は受理済み Event を返す。

Request parameters

content-type header required application/json。
x-request-id header optional 相関 ID。未指定時は API が生成する。
walkId path required 対象 Walk の UUID。

walkId path required 対象 Walk の UUID。

Query

なし

なし

POST/v1/walks/:walkId/finish（距離・pace）

Finish の確定待ち・冪等・エラー契約は縦切り 5 のまま。 この縦切りで Completed 応答の距離と pace を経路由来値へ更新する。

Response Body（距離・pace）

200 の Completed Walk で、 distanceMeters は DynamoDB 確定 TrackPoint を recordedAt 順に結んだ経路長（メートル、整数）。 TrackPoint 0件または距離 0 のとき distanceMeters は 0、 paceSecondsPerMeter は null。 距離が 1 以上のとき paceSecondsPerMeter は durationSeconds / distanceMeters。
