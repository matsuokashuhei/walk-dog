Event + Detail 画面

Recording は距離・pace と Participant 別 Event 操作を表示する。 Event 失敗は同じ内容で手動 Retry する。Completed から Walk Detail へ進み、経路・距離・時間・Event を見る。

Recording 中の距離・pace は端末が保持する TrackPoint から算出する。 Finish / Walk Detail の距離・pace は DynamoDB 確定点の経路長。 履歴一覧はこのセッションに含めない。Photo は含めない。

コンポーネント一覧

  • RecordingMetrics — 経過時間・距離・pace（端末点）
  • ParticipantEventActions — Dog ごとの Pee / Poop / Sniff / Greet
  • EventOutboundQueue — Event の永続送信と同一 payload の手動 Retry
  • CompletedSummary — Finish 後の時間・距離・pace と Walk Detail 導線
  • WalkDetail — /walks/:walkId の経路・メトリクス・Event 一覧

イベント一覧

  • onEventPress — eventId と発生時刻・位置を固定し、Event を送信キューへ載せる
  • onEventAccepted — 送信成功。失敗表示を消す
  • onEventRetryableFailure — 「記録に失敗しました」と手動 Retry
  • onEventRetryPress — 同じ eventId・種別・Participant・時刻・位置で再送
  • onViewWalkDetail — Completed から /walks/:walkId へ遷移
  • onWalkDetailLoad — GET /v1/walks/:walkId で経路・Event・メトリクスを表示
